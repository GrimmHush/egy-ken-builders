## Anti-Patterns Verdict

**LLM assessment:** Not AI slop. Committed navy/steel/amber identity, blueprint motifs, a real scroll-scrubbed hero film, seeded SVG placeholder art, and disciplined motion. The per-section eyebrow was already deliberately removed (commit 802aef8). Weakest tells: the home services section is an identical icon-card grid, and Fraunces is a saturated AI-era font choice (locked brand decision — identity-preservation wins, but worth knowing).

**Deterministic scan (CLI, src/):** 0 findings — clean.

**Browser detector (home page, live DOM):**
- `low-contrast` ×5 — 2.7:1 (needs 4.5:1), text #d9842c (amber-deep) on #f6f6f4 (bone). Confirms the manual finding: scrolled-nav active link, numbered value markers, ghost-CTA hover.
- `gray-on-color` ×12 — concrete #b8bbba on navy #042c41/#053e5c. Passes AA (~7:1) so not an accessibility bug, but neutral gray on a deep color reads washed out; tinting the light tone toward the navy/steel hue would look richer. Craft note, not a defect.
- `all-caps-body` ×1 — the 38-char hero kicker; it's a label, not body copy. Borderline false positive.
- `gpt-thin-border-wide-shadow` ×1 — the shadow-card token pairs 1px borders with 40px-blur shadows, a known template tell. Subtle here; low priority.
- `overused-font` — Fraunces carries 37% of rendered text.

## Overall Impression

This is a genuinely premium build — the scroll-scrubbed hero film, the coherent industrial-refined system, and the trust architecture (NCA/KRA/FIDIC woven through every page) put it far above the template tier. The three things holding it back: the first viewport says nothing (video only, no name/value/CTA), the ~25 MB hero video fights the site's own mobile-first performance principle, and a handful of AA contrast failures contradict the locked palette guardrails. All three are fixable without touching the design language.

## What's Working

1. **The hero scrub is the signature.** Line-by-line reveal choreography over an all-intra film, with a hydration-safe reduced-motion fallback (static SVG + instant reveals). It feels engineered — which is the brand.
2. **Trust architecture.** Registration numbers, compliance grid, FIDIC framing, credential footer strip — exactly what institutional investors and developers scan for, treated as featured content.
3. **Craft depth.** noscript reveal fallback, on-brand 404, sitemap/robots/OG image, data-driven content files, consistent micro-interactions (link-underline draws, hover lifts, arrow nudges).

## Priority Issues

**[P1] The fold is message-free.** At scroll 0 the viewport shows only the clipped video and a "Scroll" cue — no headline, no company name (beyond the small logo), no CTA. First impression carries zero value proposition; on slow connections it's a dark box. **Fix:** make the kicker + first headline line visible at progress 0 (start revealed, scrub the rest), so the fold always answers "who is this?" **Command:** /impeccable polish (hero reveal slots).

**[P1] ~25 MB hero video, preload="auto", no poster.** Mobile-first Kenyan audience on variable networks; the site's own principle is "fast on any device" and Lighthouse mobile ≥ 90. **Fix:** add a poster frame; serve a lighter mobile rendition (or static image below md); consider crf 26–28 tier (~15–18 MB) as the mobile source. **Command:** /impeccable optimize.

**[P1] AA contrast failures (detector-confirmed, 2.7:1).** amber-deep on bone: active nav link when scrolled (14px), ghost-CTA hover, numbered markers; plus placeholder text at 3.2:1. Contradicts the palette guardrails in the approved spec. **Fix:** darken the on-light amber text role to ≈ #9a5a17-tier (or switch active/hover states on light surfaces to steel), and darken placeholder color. **Command:** /impeccable polish.

**[P2] Mobile pinned-hero crop.** At 375×812 the hero column (~1100px) exceeds 100svh, so the sticky un-pins early and the headline crops off-top while stats are still revealing (verified). **Fix:** tighten mobile spacing/stat sizing so the composition fits, or unpin/shorten the scrub below md. **Command:** /impeccable adapt.

**[P2] Keyboard/AT gaps.** No skip link (spec §10 requires one); the open mobile menu doesn't trap focus — background stays tabbable. **Command:** /impeccable harden.

**[P2] Lead-gen hardening.** Contact API has no honeypot/rate-limit (spam magnet once live), and Resend env is unconfigured so leads only log to console — known launch blocker. **Command:** /impeccable harden.

## Persona Red Flags

**Casey (distracted mobile, 3G):** the 25 MB video and the cropped mobile headline are hers; otherwise thumb-friendly — full-width CTAs, 56px WhatsApp FAB in the thumb zone.

**Sam (keyboard/screen reader):** 2.7:1 active-nav/hover states, no skip link, focus not trapped in the mobile menu. Focus rings and the reduced-motion path are genuinely good.

**Jordan (first-timer):** the blank fold can read as "page still loading"; after the first scroll the journey is obvious and reassuring.

**Riley (stress tester):** validation solid, double-submit guarded, every filter category non-empty, 404 covered. Nothing broke.

## Minor Observations

- Footer "Services" links all point to /services with no per-service anchors — add section `id`s and deep-link.
- Projects grid: six near-identical navy skyline placeholders on the most trust-critical surface (known: awaiting client photos — this is the #1 content unlock).
- Home services grid is the most template-shaped section; the services page's alternating rows are stronger. Consider differentiating the flagship padel division card.
- Testimonials from the approved spec are absent entirely (awaiting client) — a missing trust layer.
- /services LCP image (padel-court.png) needs `priority` (Next.js console warning).
- JSON-LD lacks `geo` and `sameAs`; social links are "#" placeholders (known).
- "A seamless journey from vision to reality" heading + ProcessSteps repeats verbatim on Home and Services.
- Detector craft note: consider tinting concrete text on navy sections toward the navy hue for richness.
