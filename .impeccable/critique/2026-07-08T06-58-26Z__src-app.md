## Anti-Patterns Verdict

**Does not read as AI-made at first glance.** Real photography, a real hero film, scroll-orchestrated typography, verifiable credentials, and Kenyan-specific details give it a specific voice. No side-stripe borders, gradient text, glassmorphism-default, per-section eyebrows, or text overflow at 375/768/1440. Numbered markers (01–05) appear once on a real process sequence.

Borderline items: the hero ends on a backdrop-blur glass card with 4 count-up stats — structurally the banned hero-metric template, saved by real content per the brand's trust strategy. The rule-amber + tracked-uppercase kicker repeats on every page hero — one consistent named system, but the only heading grammar the site knows. Fraunces + italic amber emphasis is reflex-reject-listed but locked brand identity (identity-preservation wins). **The real tell is placeholder SVG skyline art** sitting in trust-critical slots directly beside genuinely excellent real photography.

**Deterministic scan (CLI)**: clean — 0 findings across `src`.

**Deterministic scan (browser, 5 pages)**: `gray-on-color` ~40 hits (concrete #b8bbba text on navy #053e5c / navy-deep #042c41 — passes AA contrast but reads washed out per the gray-on-color rule); `image-hover-transform` ×16 (intentional card-zoom micro-interactions — acceptable); `gpt-thin-border-wide-shadow` ×10 (the shadow-card token paired with 1px borders — deliberate elevation system, low priority); `all-caps-body` ×1 (38 chars uppercase body text on home); `overused-font` (Fraunces 34% of text on home, 27% about, 19% elsewhere); `skipped-heading` on /projects (h1 → h3 "Riverpoint", missing h2) — a real semantics gap the design review missed.

## Overall Impression

A disciplined, premium brand site that mostly delivers on "engineered, premium, assured." The scroll-orchestrated hero and the trust-as-content strategy are genuinely strong. The biggest opportunity is robustness of first paint: the two P1s mean parts of the site literally don't exist (blank sections, "0+" stats) for no-JS visitors, crawlers, previews, and flaky-connection mobile users — the exact audience PRODUCT.md prioritizes.

## What's Working

1. **The scroll-orchestrated hero is genuinely premium.** Clip-path video expansion, line-by-line headline reveal tied to scroll slots, load-time kicker answering "who is this," and a fully thought-through reduced-motion path.
2. **Trust is treated as content.** NCA 1 + registration number in credential strip and footer, KRA/OSH/Companies Act compliance, FIDIC framing, real project metrics an institutional evaluator can verify.
3. **Micro-interaction discipline.** One easing family, underline-draws, card lift + amber hairline + arrow-fill, icon chip color-swap — consistent physics, transform/opacity only.

## Priority Issues

1. **[P1] Content is invisible without the in-view trigger.** `Reveal.tsx:26` starts everything at `opacity: 0`; only `whileInView` restores it. Full-page renders shipped the Projects CTA section and a ~1,300px band of the About page blank — the failure mode the skill bans. Lead-gen sections don't exist for no-JS visitors, some crawlers, print, link previews. **Fix:** SSR content visible; apply hidden initial state only after hydration, or CSS scroll-driven animation with visible fallback. **Command:** /impeccable harden.
2. **[P1] Stats render as "0+" until count-up plays.** `StatCounter.tsx:21` initializes to 0; About trust bar reads "0+ Years' Experience" in any render where animation doesn't fire. Actively harmful for a company selling track record. **Fix:** SSR the final value; drop to 0 and count up only after hydration. **Command:** /impeccable harden.
3. **[P2] Placeholder art in trust-critical slots.** Homepage About teaser (`page.tsx:62`), About portrait, all PageHero backgrounds use flat SVG skylines beside real photos. Violates design principle #2 ("Show the work"). **Fix:** re-crop existing project photography into these slots until client assets arrive. **Command:** /impeccable polish.
4. **[P2] Mobile menu close button nearly invisible.** `Navbar.tsx:134`: open state sets `text-navy` on `bg-navy-deep` — navy-on-navy, far below 3:1. **Fix:** `text-bone` when open. **Command:** /impeccable polish.
5. **[P2] Mobile hero withholds the pitch.** At 375px the fold is one headline line + clipped video; paragraph/CTAs need ~1,200px of scrub; WhatsApp FAB overlaps the stats card. **Fix:** shorten SCROLL_HEIGHT / start reveals earlier on small viewports; add FAB clearance. **Command:** /impeccable adapt.

## Minor Observations

- `/projects` skips h1 → h3 (missing h2) — detector catch.
- Hero paragraph `text-concrete` over video sits near the contrast floor on bright sky frames; ~40 gray-on-navy detector hits suggest a bone-tinted or navy-hued light token for dark-section body text.
- One 38-char all-caps body run on home.
- Fraunces carries 34% of homepage text — display font drifting into body duty.
- "Skip to content" link paints visibly in some render states — check focus-only styling.
- Next-project card is name-only; a thumbnail would invite the click.
- Footer email `break-all` wraps mid-word; `break-words` reads better.
- Token name `--color-bone` is a cream-tell by name only; value is a true off-white (allowed).

## Questions to Consider

1. What if the hero film handed off directly into Riverpoint as a continuous case story instead of parking on a stats panel?
2. Can even one client be named with one sentence of testimony? A single named reference outweighs four anonymous superlatives for an audience whose job is verification.
3. What does the institutional evaluator download? A capability-statement PDF may be a more valuable conversion path than any visual polish.
